# Kingdom Hearts II Final Mix — Achievement Tracker

Tracker interactivo para llevar el progreso de los 50 logros de **Kingdom Hearts II Final Mix**.

El proyecto está diseñado para funcionar directamente en el navegador y guardar el progreso de cada usuario de forma local.

Demo

KH II Achievement Tracker (https://garexg.github.io/KH-II-Logros/)

Características

- Los 50 logros de Kingdom Hearts II Final Mix
- Seguimiento de progreso
- Porcentaje de completado
- Filtros por estado
- Filtros por categoría
- Buscador de logros
- Subtareas para logros complejos
- Subtareas anidadas
- Sincronización entre objetivos relacionados
- Progreso guardado automáticamente con Local Storage
- Diseño inspirado en Kingdom Hearts II
- Diseño responsive para PC, tablet y móvil

Tecnologías

- HTML
- CSS
- JavaScript
- Local Storage
- GitHub Pages

## 🎮 Proyecto

Proyecto personal creado para llevar un registro más cómodo del progreso de logros de Kingdom Hearts II Final Mix.
